# Regulatory Reporting and Data Governance Pack



## Purpose

Generate a SYNTHETIC 5,000-facility wholesale portfolio and demonstrate reporting controls, illustrative credit losses, metadata, issue aging and reconciliation. All amounts, counterparties and operational scenarios are fabricated. No network calls are required or made.

## Run

Use Python 3 with numpy and pandas. Matplotlib is optional. No pytest dependency is needed.

```powershell
python run_all.py
```

The pipeline regenerates data, CSV tables and the memo, then runs all five test scripts. After generation, each `tests/test_*.py` file also runs directly with the same interpreter. Missing required modules cause failure; install nothing during review. Matplotlib and pytest are missing in the reviewed runtime, so charts were skipped.

Edit simulation inputs, schema names, seeds and thresholds in the CONFIG block of `python/config.py`. Module-specific presentation dictionaries and chart settings use CONFIG blocks after imports. Values in these blocks are assumptions, not sourced observations.

## Methods

EAD = drawn + undrawn x product CCF. Lifetime PD = 1 - (1 - annual PD)^remaining years. Base loss = EAD x lifetime PD x LGD. Monetary inputs use per-facility rounding to cents. Overlay adds 3% of base loss, plus 15% for CRE collateral and 10% for ratings 6 to 8. Cohort PD and LGD are EAD-weighted, grouped by rating and tenor bucket.

Ending allowance = beginning allowance + provision - gross charge-offs + recoveries. Ending base plus overlay also equals ending allowance. Net charge-offs are a subtotal and must not be added again when using gross charge-offs and recoveries.

A reconciliation break is active when absolute variance exceeds $10,000 OR absolute variance / absolute GL exceeds 0.05%, after clearing amounts at or below $100. Zero GL with nonzero variance has infinite relative variance. Threshold comparisons use unrounded ratios. Positive variance means schedule exceeds GL.

## Tests

Tests verify facility-level schedule equality and totals, all injected facility IDs with no false positives, clean DQ results, nulls, short LEIs, duplicate IDs, negative drawn balances, invalid dates, infinity and missing references. They also verify catalog coverage, issue linkage, closed counts, weighted cohorts, reserve identities and reconciliation boundaries, including zero and negative GL balances. Independent scalar and Decimal calculations check commitments, lifetime allowance and gross active breaks to the cent.

## Assumptions and limits

All inputs are SYNTHETIC. This is a local educational prototype, not production software, a filing package, an accounting opinion or a regulatory compliance assessment. No real clients, employers or institution data are used.

The H.1-style CSV is an 18-field subset with project item numbers. It does not reproduce official reporting schemas, validation rules or eligibility thresholds. The liquidity report combines selected exposure proxies and a fee residual; it does not apply regulatory outflow weights. Term undrawn amounts are outside that reconciliation scope. GL entries, break ages and root-cause tags are assigned synthetic scenarios. A valuation-adjustment example replaces the former FX story because the tape is USD only.

Annual PD, LGD, CCF and overlays are assumptions. Lifetime PD compounds a constant annual PD over remaining maturity. EAD stays constant; no amortization, prepayment, discounting, macroeconomic forecast or competing-risk model is included. Funded and unfunded loss estimates are combined for demonstration. Beginning allowance and charge-offs are assumed; provision balances the roll-forward. Ending base and overlay are stock disclosures, not current provision components. No empirical accuracy or coverage target is claimed.

Borrowers are sampled with replacement from a 3,800-entry pool; not every directory entry appears in the tape. Synthetic LEIs have 20 alphanumeric characters but no validated registration or checksum. Referential tests use the persisted clean synthetic facility/collateral pairs, not an independent master system. Eighteen rules cover every schedule field, but they do not establish complete business or regulatory validity. The six injected defect categories establish detection on that benchmark only, not universal DQ coverage.

Issue ages and 12 closed durations are assumed examples, not observed remediation performance. Their mean close time is 37.42 days. The shared summary count column contains the closed count in the historical row. BCBS scores use a project-defined evidence scale: 0 absent, 1 partial, 2 repeatable local controls, 3 independently validated operation. No regulatory score standard is asserted. Principle names are illustrative references; no primary regulatory documents were fetched or checked because this project must stay offline.

The memo has two logical pages separated by an HTML print break. Markdown viewers may ignore that break; no exact physical pagination is guaranteed. Optional charts require matplotlib. Determinism was checked using this interpreter and installed dependency versions; cross-version identity is not guaranteed.
